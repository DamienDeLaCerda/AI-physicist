# Physics AI

A field guide for research groups using [Get Physics Done](https://github.com/psi-oss/get-physics-done), the open-source agentic workflow from [Physical Superintelligence PBC](https://www.psi.inc).

The guide is the site: open `index.html`, or publish this repository with GitHub Pages.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder **`/ (root)`**, then save.

The site uses relative asset paths, so it works both at `https://<user>.github.io/<repo>/` and at a user-site root.

Command names follow the upstream README for Get Physics Done 1.2.2. When the help text inside your runtime and this guide disagree, follow the runtime.

Get Physics Done is Apache-2.0 software from Physical Superintelligence PBC. This guide is an independent orientation to that system.
